# Snip

Snipping Tool из Windows 11 для Noctalia + Hyprland.

Бинд замораживает экран и открывает плоскую панель сверху по центру:

```
[Фото|Видео] │ Область  Окно  Экран  Все │ (Звук Микр.) │ Цвет  Текст  QR │ Закрыть
```

- **Фото**: выбор поверх замороженного экрана. Окна подсвечиваются при наведении (`slurp -r`).
  Снимок берётся из замороженного кадра в момент выбора режима (не с живого экрана) и
  открывается во встроенном редакторе Noctalia (`noctalia msg annotate`).
  - **Окно** снимается по геометрии выбранного окна; клик по рамке тоже выбирает окно
    (хитбокс расширен на border), а в кадр попадает точная клиентская область.
  - Курсора на снимке нет при hardware-курсоре. Если Hyprland использует software-курсор,
    он запекается в кадр — в конфиге Hyprland нужно:
    ```lua
    hl.config({ cursor = { no_hardware_cursors = false } })
    ```
  - Ограничение: замороженный кадр — это уже скомпонованная картинка. Если окно было
    перекрыто другим, в вырезку попадёт перекрытие; скрытую часть восстановить нельзя.
- **Видео**: область, окно или монитор → отсчёт 3-2-1 → `gpu-screen-recorder`. Звук системы и микрофон включаются
  тумблерами и сводятся в одну дорожку. На NixOS нужен `programs.gpu-screen-recorder.enable = true`
  (setcap для `gsr-kms-server`), иначе каждый старт спрашивает пароль. Мини-панель
  показывает таймер и кнопку «Стоп». Повторное нажатие бинда тоже останавливает запись.
  Курсор в видео остаётся (`-cursor yes`). Путь к файлу копируется в буфер обмена.
- **Цвет** (`hyprpicker`), **Текст** (OCR, `tesseract`), **QR** (`zbarimg`): результат
  копируется в буфер обмена. Область для OCR/QR выбирается по замороженному кадру.

Клавиши в панели: `1–4` режимы, `5–7` утилиты, `Tab` переключает Фото/Видео, `Enter`
повторяет последний режим, `Esc` отменяет.

## Подключение

```sh
noctalia msg plugins source add snip path ~/noctalia-snip
noctalia msg plugins enable bebra/snip
```

Hyprland (Lua):

```lua
hl.bind("SUPER + SHIFT + S", hl.dsp.exec_cmd("noctalia msg plugin bebra/snip:service all open"))
```

Зависимости: grim, slurp, wayfreeze, imagemagick, jq, hyprpicker, tesseract, zbar,
gpu-screen-recorder, wl-clipboard.
